# React mini project (2 weeks: 41 and 43)
The assignment is to create a simple React application that displays a list of books and allows users to add new books to the list. The application should have the following features:
- A form to add new books, including fields for the book title and author.
- A list that displays the books that have been added, including the title and author.
- A button to remove books from the list.
- A button to mark books as read or unread.
- A button to edit the title and author of a book.
- The application should use React state to manage the list of books and their read/unread status. The application should also use React props to pass data between components.
- The form and the list view should be separate components, and the application should use React hooks to manage state and side effects.
