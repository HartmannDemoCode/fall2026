Earlier in the semester, we built a bunch of APIs.
So the idea is to build a cool React frontend applications
that utilize the API you built.

The frontend applications should be built with React, and you should use the tech stack
we have used so far. This means that you should use React, React Router, and styling with CSS.
The frontend applications should be deployed to a Digital Ocean Droplet.
You should also use the deployment pipeline we have introduced. So GitHub Actions,
Docker Compose file, and Watchtower to keep the frontend Container up to date.
You should also use Caddy to serve the frontend over HTTPS on a sub-domain.

Be creative and have fun with it.

## General Requirements

The most important requirement is that you have fun and learn something new.

Secondarily, you should:

- Use React
- Use React Router
- Use CSS Modules for styling components
- Deploy the frontend to a Digital Ocean Droplet
- Use GitHub Actions for CI/CD
- Implement login and authentication using JWT
- Implement error handling and give feedback to the user
- Implement CRUD operations as needed

Thirdly, you should:

- Look to the [frontend exam questions for inspiration](/exam/frontend/exam-questions),
and to make sure you cover the topics in your SP-3 portfolio application.
