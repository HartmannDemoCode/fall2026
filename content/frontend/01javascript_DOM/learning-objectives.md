# Learning Objectives for TypeScript and DOM manipulation

## TypeScript and Webdevelopment

1. **DOM Manipulation:**
   - Understand the Document Object Model (DOM) and how to manipulate it using TypeScript.
   - Use TypeScript to select, modify, and create HTML elements dynamically.
   - Understand the event-driven programming model in TypeScript and how to handle user interactions.

2. **Functional Programming Concepts:**
   - Apply functional programming concepts in TypeScript, leveraging higher-order functions and immutability. This includes the use of `lambda expressions`, `map` and `filter`.
   - Recognize and exploit the benefits of functional programming in real-world scenarios.

7. **TypeScript Debugging Proficiency:**
    - console.log()
    - Master browser developer tools for TypeScript debugging.
    - Be able to identify and resolve common TypeScript errors.
