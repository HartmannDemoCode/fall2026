# Learning Objectives

## Deployment workshop

- Know how to get a domain name and set up a DNS record and name server.
- Know how to get a droplet linux server at Digital Ocean and install Caddy in a docker container.
- Know how to deploy a React application to a linux server using Caddy.
- Know how to use simple cli commands to manage a linux server and docker containers.
