# Learning Objectives

## Error handling
1. Understand the importance of error handling in React applications.
2. Learn how to implement error boundaries to catch and handle errors in React components.
3. Understand how to display user-friendly error messages and fallback UI when errors occur.

## React Hooks
1. Understand the concept of React Hooks and their role in managing state and side effects in functional components.
2. Learn how to use the `useState` hook to manage component state.
3. Learn how to use the `useEffect` hook to handle side effects such as data fetching and subscriptions.
4. Understand how to create custom hooks to encapsulate reusable logic and improve code organization.
5. Learn how to use the `useContext` hook to access and manage global state.
